◆ SET UP FOR YOUR SITE

{% if setup %}{{ setup.done }} OF {{ setup.total }} CHECKED{% endif %}

Every site is different. The monitor only knows yours through these four things, so do them in order and check back after moving a camera.

  1. NAME EACH CAMERA {{ setup_chip('cameras') }}

    Set CAM_STREAMS in .env as label=rtsp-url, one per camera, comma-separated. One camera or many both work. The labels show up in alerts and the line editor. After editing, run docker compose up -d.

  2. DRAW THE LINES {{ setup_chip('lines') }}

    In LINE EDITOR, draw a red line where water becomes dangerous and an amber line where it becomes a warning. The lens with the red line decides CRITICAL: water must reach that line. Draw it where water actually arrives from at your site.

  3. DESCRIBE YOUR SITE {{ setup_chip('description') }}

    Fill in Reference description below: what each lens shows, which lens decides CRITICAL, and what 0 / 50 / 100 look like at your site. Claude reads it on every check.

  4. CHECK THE REST

    Warning/critical levels (only used when no red line is drawn), your coordinates for the rainfall chart, and the check interval and model, which set how much Claude usage you spend.
